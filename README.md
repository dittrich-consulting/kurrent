# Kurrent practice

Installable, offline handwriting practice for Android Chrome. Finger drawing, image recognition, optional confirmed-motion structure feedback, and device-local statistics. No server-side storage, analytics, or account in the app.

Open https://dittrich-consulting.github.io/kurrent/ in Chrome and use Install app / Add to Home screen. Wait for “Ready for offline practice”, then test in airplane mode. Keep the same site address: storage belongs to this site and device. Clearing browser/site data removes local statistics; use Export progress for backups.

## Hosting
Upload the contents of this folder to the repository root. In Settings → Pages select Deploy from a branch, main, / (root), Save. HTTPS is provided by GitHub Pages.

## Motion data
Bundled confirmed motions cover 61 characters and are cached offline. Image and structure recognition work without importing progress. No practice history or personal settings are included. No motion editor is included.

Build 8ed127bc30b5. Updates download when connected; use the Update app button when offered. Updates preserve local statistics.
